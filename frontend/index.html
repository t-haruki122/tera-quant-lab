Claude 連携（APIトークン）

Claude はウォッチリスト、保有資産、アラート、株価データを参照し、結果を保存せずにバックテストを実行できます。データや設定は変更できません。トークンの全文は作成時に一度だけ表示されます。漏えいした場合はここで無効化してください。

トークンは Claude Code の設定（~/.claude.json）に平文で保存されます。共有 PC で使った場合や漏えいした場合はここで無効化してください。設定後は Claude Code を再起動し、/mcp で接続を確認してください。
