# FRONTEND Guide

プロジェクト全体説明へ戻る: [README.md](../README.md)

## 概要

フロントエンドはビルドステップなしの ES Modules 構成です。`index.html` では `type="module"` で `frontend/app.js` を読み込み、各機能モジュールを `import` して構成しています。

## 主要ファイル

- エントリポイント: `frontend/app.js`
- APIヘルパー: `frontend/js/api.js`
- 共有状態: `frontend/js/state.js`
- 詳細表示: `frontend/js/detail.js`
- 価格チャート: `frontend/js/chart.js`
- 銘柄比較: `frontend/js/comparison.js`
- ハッシュルーティング: `frontend/js/router.js`
- 財務チャート: `frontend/js/financial-chart.js`
- リスト管理: `frontend/js/list.js`
- 認証UI: `frontend/js/auth.js`
- アカウント設定 `frontend/js/account.js`
- ポートフォリオとアラート管理 `frontend/js/portfolio.js`
- アラート判定のポーリングと通知 `frontend/js/alerts.js`
- 統計表示: `frontend/js/stats.js`
- ユーティリティ: `frontend/js/utils.js`

## 実行方法

バックエンドを起動すると、ルート (`/`) で `frontend/index.html` が配信されます。

```bash
uv run uvicorn app.main:app --reload --reload-dir app
```

ブラウザ: `http://localhost:8000/`

## 画面へのリンク

| ハッシュ | 画面 |
|---|---|
| `#/` | ウォッチリスト |
| `#/stock/7203.T` | 銘柄詳細（既定期間は3M） |
| `#/stock/%5EN225?period=1Y` | 指定期間の銘柄詳細 |
| `#/backtest`、`#/backtest?symbol=7203.T` | バックテスト。銘柄指定時は入力欄に反映 |
| `#/portfolio` | ポートフォリオと価格アラート。未ログイン時はログインを案内 |
| `#/stats` | システム統計 |

期間は `1M`、`3M`、`6M`、`1Y`、`2Y`、`10Y` から選べます。銘柄は URL エンコードし、API と同じルールで検証します。不正なハッシュはブラウザーの履歴を増やさず `#/` に置き換え、ウォッチリストを表示します。ブラウザーの戻る・進むで銘柄や期間を移動でき、ログインやログアウト後も現在のルートを保持します。

## 株価チャートと騰落率の比較

既定はラインで、ラインとローソク足の選択は localStorage に保存します。10Y のローソク足は `interval=1wk` で週足を表示し、SMA・RSI・MACD・ボリンジャーバンドも週足で計算します。その他の表示は日足です。出来高・RSI・MACD は株価と同じ日付ラベルの別パネルで表示します。ローソク足は上昇を中抜き、下落を塗りつぶしで描き、ツールチップに日付と四本値を表示します。

「騰落率の比較」では現在の銘柄に4件まで追加できます。選択中のウォッチリストからの候補とティッカーの直接入力に対応します。選択期間の日足終値を各銘柄から取得し、取得できた全銘柄に共通する取引日だけを表示します。最初の共通取引日を 0% として `(当日の終値 / 最初の終値 − 1) × 100` を描きます。市場ごとの休場日には補完を行いません。取得失敗は銘柄ごとに表示し、取得できた銘柄で比較を続けます。同時取得は現在の銘柄を含む最大5件で、同じ履歴の取得中リクエストとキャッシュを共有します。

## ウォッチリスト

ログイン後、銘柄ダッシュボードのセレクターから表示するリストを選びます。リストを新規作成し、選択中のリストを名前変更できます。削除は確認後に実行し、デフォルトリストでは削除ボタンが無効になります。最後に選んだリストをユーザーごとに localStorage に保存します。

リストの新規作成、名前変更、削除確認、銘柄メモの編集は画面内のダイアログで行います。Esc で閉じ、Enter で送信できます。メモ欄では Shift＋Enter で改行します。

リストの銘柄情報とメモは概要APIで一括取得します。取得できなかった項目がある行にはエラーを表示し、取得済みの値も表示します。タグ絞り込み、`#タグ` 検索、列の並べ替えは選択中のリストに適用されます。「CSVをエクスポート」から選択中のリストを保存できます。

## ポートフォリオと価格アラート

「ポートフォリオ」では円換算の評価額・取得額・含み損益・損益率を表示します。保有銘柄は列見出しのボタンで並べ替えられ、ティッカーから銘柄詳細に移動できます。構成チャートの下には銘柄別の評価額と構成比をテキストでも表示します。評価に使えなかった銘柄やキャッシュの代用は画面で案内します。「CSVをエクスポート」から登録した保有銘柄をExcel向けのUTF-8 BOM付きCSVで保存できます。

銘柄詳細の「ポートフォリオに追加」「アラートを追加」ではティッカーと現在価格を初期入力します。すでに登録した保有銘柄は追加ダイアログから編集に移れます。保有銘柄と価格アラートはポートフォリオの一覧から編集・削除できます。

ログインまたはセッションの復元から約3秒後に価格アラートを初回判定し、以降はページを表示している間に5分ごとに判定します。非表示のタブでは新しい判定を一時停止し、ログアウトで終了します。HTTP 429・5xx や通信エラー時は再試行の間隔を延ばします。アラートが発火するとアプリ内に表示し、ブラウザ通知の許可があればOSの通知も送ります。「ブラウザ通知を有効にする」を押したときにだけ許可を求めます。

ブラウザ通知には HTTPS または localhost のセキュアコンテキストが必要です。LAN内のIPアドレスに平文HTTPでアクセスする場合、ブラウザ通知の拒否時、未対応ブラウザでは、アプリ内の通知を使えます。LAN内でHTTPSを使う手順はデプロイガイドのリバースプロキシ設定を参照してください。 [nginx・HTTPSの設定](DEPLOY.md#リバースプロキシ)

## アカウント設定

ログイン後にユーザーメニューの「アカウント設定」を開きます。

- パスワード変更では現在のパスワードと新しいパスワードを入力し、確認欄との一致を画面でチェックします。変更後は新しいトークンで操作を続けられます。
- 「他の端末からログアウト」は、このブラウザーを含むすべてのセッションを終了します。
- 「JSONをエクスポート」で全リスト、メモ、保有銘柄、価格アラートを保存します。インポートではファイルを選び、既存データへの追加か、確認後にバックアップの内容で置き換える方法を選びます。処理後に取り込み件数とスキップ理由を表示します。
- アカウント削除にはユーザー名の再入力と現在のパスワードが必要です。削除後はログアウトします。
